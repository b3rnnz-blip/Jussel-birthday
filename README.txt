Birthday Surprise for Jussel
============================

Open index.html in a modern browser to run the program.

Folders:
- assets/fonts/  Local copies of the Google Fonts used by the design (if downloaded).
- assets/images/  Extracted memory photo used by the page.
- assets/logo/    Standalone birthday-heart logo SVG.

Notes:
- The page also contains its CSS and JavaScript inside index.html.
- Background music is generated by WebAudio in the page; no music file is required.
- The original page loads Google Fonts from the web. The included font files are provided as separate assets, but the CSS has not been rewritten to local @font-face rules automatically.
